Как получить бесплатный ключ Google Gemini:

1. Открой aistudio.google.com/app/apikey
2. Войди через Google-аккаунт
3. Нажми «Create API key»
4. Скопируй строку (начинается с AIza...)
5. Вставь её в поле выше

Лимит бесплатно: 1500 запросов в день.
Ключ хранится только в твоём браузере.
